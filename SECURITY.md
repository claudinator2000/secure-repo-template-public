# Security policy

Do not disclose suspected vulnerabilities, credentials or sensitive data in a
public issue, discussion or pull request.

Report privately. Where the repository's **Security** tab offers **Report a
vulnerability**, use it; GitHub provides this private vulnerability reporting
for public repositories. Otherwise use the private security contact named in
the repository README. If neither exists, open an issue that asks only for a
private contact path, without vulnerability details.

A security report should identify the affected revision, expected and observed
behavior, reproduction conditions, impact and any known mitigations. Never use
real credentials or third-party data as proof.
